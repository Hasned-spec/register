hasned.dev API

Free, no-login JSON utilities. Base URL: https://hasned.is-a.dev/x402/paid

All endpoints accept GET (query params) and POST (JSON body). Responses are JSON: {"ok": true, ...} or {"ok": false, "error": "..."}.
