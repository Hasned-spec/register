Hosted API


The same utilities are available as plain-HTTP JSON endpoints for scripts and CI jobs
(GET/POST https://hasned.is-a.dev/x402/paid/<tool>). Tools include:
hash, uuid, base64, qrcode, csv2json, json2csv, yaml2json, jwt-decode, url tools,
dns-lookup, whois, geoip, crypto-price, fx-rates, wayback, html2md.
All endpoints have a free, rate-limited tier. See endpoint docs.
